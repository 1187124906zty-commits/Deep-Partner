# 公开快照范围

快照日期：2026-11-05。

包括工作台、DeepTutor 原生运行代码及维护前端、Dify 官方固定版本、交付适配桥、原生扩展、集群运行器、桌面端和已有工程文档。

生产运行时的 Python 源码优先于本机旧副本；统一前端保留本机维护源码，其复用的原生组件另取集群维护版本。Dify 固定版本来自官方 GitHub 归档；本仓库不包含该系统的生产数据库。

以下内容不在公开仓库中：

- API key、访问 token、账号密码、私钥、SSH 身份文件和实际服务认证配置。
- 运行数据库、会话内容、私有研究项目、上传附件和已下载论文。
- 虚拟环境、node_modules、编译缓存、历史安装包和大型执行结果。
- 旧验收输出中的私人文件清单。

生产域名、IP 和个人绝对路径使用示例值表达。部署脚本保留结构供审查，迁移时必须配置真实环境。

上游公开测试中的虚拟凭据、签名测试向量和默认示例值，保留在对应测试/示例中；这些不代表本系统的有效凭据。发布检查使用明确到文件及位置的已审阅例外，不对整个测试目录关闭密钥扫描。

这次发布验证的是源码归集、公开内容检查与仓库上传。它不声明所有历史验收已重新运行，也不声明已完成四系统的端到端故障恢复验收。
