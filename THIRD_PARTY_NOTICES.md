# Third-party components and source provenance

This repository is an engineering review snapshot assembled from several existing projects.
It does not relicense those projects or claim authorship of their upstream code.

- **DeepTutor**: HKUDS/DeepTutor. The local source baseline is commit
  a31d82624c27d75f4e771d4fcb78dce16470b383. Production Python files and the maintained
  frontend source are overlaid. See native/DeepTutor/LICENSE and its notices.
- **Dify**: langgenius/dify, tag 1.18.0, commit
  50abea97062110044f15d0e03ccecadd9ccc87ca. Source downloaded from the official
  GitHub archive. See native/Dify/LICENSE, including its additional conditions.
  Dify integration and operational changes are kept in deployment.
- **Paper2Slides and other workbench vendors**: preserve the original notices
  in workbench/licenses and workbench/vendor.
- **Desktop dependencies and assets**: see desktop/licenses and dependency manifests.

New project-specific files are published for review by the repository owner.
No blanket license grant for all original project-specific code is added here.
Refer to per-component licenses and contact the owner for permissions not covered by them.
