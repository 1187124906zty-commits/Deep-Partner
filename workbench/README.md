# 研究工作台

正式入口：[统一研究空间](https://tutor.example.invalid/research/)。当前 DeepPartner 0.4.1 将原生研究会话、流式执行和工作台成果放入同一个界面。主体外框、侧栏、顶栏、Dito 与完整设置直接复用生产 Tutor 组件；项目导入在 Dito 独立侧边会话中进行，保持主会话内容和位置。宽屏支持成果与对话并排，正式批注及图形执行仍保留原有工作台交接链路。共享前端位于 `unified-ui/`，以同一静态包发布到网站及 Tauri/WebView2 桌面；字体 Geist/Lora 随包内置。

当前前端 Slurm `25195860` 完成 0:0，完整类型检查零错误、30 项测试通过；本轮后端 19 项、原生单元 15 项、原生集成 3 项通过。实际网站和最终 WebView2 程序已检查，Dito 的真实独立回答、已保存侧边线程恢复、主会话不变、完整设置与 PDF 模块加载均已核验。当前交付及范围见 `D:/Development/询问/dify-research-deployment/docs/DeepPartner0.4.1实际修复.md`。下文保留工作台业务能力与专项验证资料。

工作台现提供 37 个任务工具的 MCP 安装包，连接同一账户、项目和产物。安装与完整参数见 `mcp-package/USAGE.md`、`mcp-package/TOOL_REFERENCE.md`；网站“工作台设置 → 使用与 MCP”可下载同一已验收 ZIP。Google Scholar MCP 已安装并真实检索，Crossref 保留为题录核验和明确可选来源；WoS/JCR 等授权按实际配置显示。Dify 应用 `5c9d68ae-3847-4774-8e94-ecbfa9543e25` 已注册这 37 个工具，现有 11 节点成果交付流已实际跑通。当前完整验证范围和界面待补项见 `verification/工作台与Dify交付验收.md`。

程序文件点击后在旁侧打开，支持暗色语法高亮、行号和文件/行号批注。文献阅读使用工作台自己的界面，复用 PDF.js 显示与 NeoRead Go 解析、翻译协议，支持目录、搜索、双语对应、按页审阅和图片精修；不再嵌入整页 NeoRead 应用。每个研究项目保留独立的解析数据。PPT 使用实际渲染页、缩略图和逐页批注，Agent 对话与按页排序的批注处在相邻分块，保留 PPTX/PDF 导出。

论文默认打开简洁的双语稿件，原文和译文都可直接修改。新改文字只在保存前临时显示红色；点击“保存修改”或 Ctrl+S 后恢复正文颜色，保存的结构与导出文件不包含这种临时装饰。中英互译可使用已配置的工作台 API 或账户模型，也可把编辑过的译稿作为翻译来源。模板与 Word/PDF/TeX 导出集中在一个面板中；图片与引用的设置在点选对应对象时出现。

正文引用有稳定身份，并与文末条目、文献库的“参考文献”共用一份记录。点击引用可查看来源题录、复制 BibTeX、使用 DOI 或标题检索 Crossref，或请 Agent 推荐替换文献并修订对应段落。替换需要当前稿件版本，保留原引用身份和旧稿；只有题录/摘要时不声称已核验全文。文献库另分“方法框架”“验证数据”和“阅读材料”，支持按用途查看与归类。处理、模板切换、导出和保存图形时显示对应的动态遮罩。

图形在当前工作区内展开。已有 Matplotlib 对象的结果支持点选、双击配置、拖动，调整文字、字体、字号、曲线与点型、图例、云图、色条和多子图布局。分块布局分别保存行列、块间距和块内的相对位置；辅助线可以开关，不进入导出。修改即时预览，保存才写入当前 PNG/PDF/SVG、稿件图片引用和绘图样式；原图与修改原因、时间保存在可回查垃圾箱。保存的样式通过项目 `.workbench/figure_runtime.py` 被原绘图程序复用。普通位图保留放缩、裁剪、标记和带源程序索引的 AI 会话，不冒充可直接编辑的绘图对象。

“问题”页汇集当前项目的原始批注、文件/页码/原文线索、AI 归纳、相关会话、修改与回执。批注只显示在其所属文件、页面或文献，历史在数据库保留。没有可用模型时，仍保存原始问题，并明确归纳未完成。

工作台内置输出标准，供后续任何获授权的 API/模型使用。Matt Pocock 选定原始技能与 MIT 许可证、Stop That Shit，以及针对稿件、翻译、知识分类、PPT、图形和审阅的产品约定位于 `vendor/workbench-skills`。DeepCode 的复现流程作为独立编写的输出约定，原生代码执行仍使用已接入的 DeepTutor/DeepCode 通道。

- `GET /research/llms.txt`：通用输出约定。
- `GET /research/api/standards`：技能目录、原文和接入导航。
- `GET /research/api/schema`：当前 API 定义。
- `GET /research/api/projects/{id}/agent-context?task=code|paper|translation|literature|slides|figure`：当前项目、文件位置、相关技能与回执格式。
- `POST /research/api/projects/{id}/agent-receipt`：记录问题、实际修改、验证结果及限制。
- `GET /research/api/figure-runtime`：供绘图程序注册对象和复用保存样式的 Python 模块。

接口沿用当前账户认证和项目所属关系。翻译、图形对话、问题归纳、PPT 规划等模型调用会携带相应输出约定。NeoRead 原始翻译协议保留段落标识、原文对应与 JSONL 输出；工作台模型桥接保留流式和多模态消息。

## 模板与示例

三份官方 Word 来源及作者模板位于 `templates/manuscripts/source`：中国工程科学、Elsevier CIRP Annals 2026、Springer AAS 2025。保留原始模板和来源；当前单栏审阅适配不冒充出版社最终排版。PPT 使用用户参考文件的母版、布局、主题与字体，通过 Paper2Slides 组织已有内容，再生成可编辑文字、表格及图片。
