# 模板保真

原生 PPTX/POTX/DOCX/DOTX 优先作为结构依据。PDF、截图或发表版面可以支持视觉观察，不能仅凭像素宣称已恢复原生母版、所有字体、对象关系和完整编辑能力。保留原件，在工作副本修改。

## 提取实际规则

PPTX 检查页面尺寸、母版/版式/主题关系、占位符类型与层级、背景、标志、页脚和页码；读取主题与显式覆盖中的颜色、字体和文本样式，以及边距、缩进、对齐、段前后距、行距、文字框尺寸、组合和裁切。中英文、数字、公式与代码可能使用不同字体。样式为继承值时查上层关系，不能把空属性当默认字体。

优先复用原生模板页面、版式和占位符，只在允许范围内替换内容。保留多个文本 run 的语义样式；整框 clear 后重写、只复制首个 run、将主题色固化为 RGB 都可能丢失要求。若模板本来使用局部覆盖，保留其局部含义。

DOCX 检查节/纸张/页边距、分栏、页眉页脚、样式与 basedOn、文档默认值、直接格式、中英文字体、字号、段落/列表、图注表注、公式和参考文献。优先写入对应段落/字符样式，处理会覆盖样式的遗留直接格式。公式字体与正文分别核对；修改 Normal 不足以证明全文匹配。

为本次任务记录实际模板中的规则及来源位置。必要时由现有模板导入工具输出 profile/manifest，包含适用页面或样式、要求值、来源和允许变动范围。缺失规则留空或标为未知，不推测成硬性规范。

## 执行和核验

检查生成文件实际包含的字体声明与主题关系，并核对渲染环境可用字体。对没有相应字形或许可的字体说明具体影响；未经用户接受的字体替代保持为偏差，不能宣告严格一致。字体安装与嵌入遵守原授权。

按模板不变项做结构比较，按内容变化检查页面渲染。文本更长后检查行数、溢出、叠字、裁切、图注、页眉页脚、表格和公式。调整限制来自用户与模板，不能以自动缩小字号为通用修复。

相同内容的模板测试可做视觉差异检查；内容改变时，逐像素差异不能代表风格违例。以实际模板约束判断布局变化，并看最终导出环境是否出现字体回退。对象可编辑性从原生结构与实际编辑结果核对。
