# 期刊要求与表达

先确定期刊、文章类型、投稿阶段和目标格式。阶段会改变要求；用户尚未选择目标时可比较候选，不虚构统一模板。当前作者指南和指定模板从官网核验，保存链接、查询日期、版本/适用类型与原文定位。

将材料用于各自适用的问题：

- 官方作者指南、投稿清单、明确模板：确定格式、长度、文件与报告要求。
- 与目标研究领域和文章类型相近的真实论文：观察问题引入、主张范围、方法细度、结果/讨论组织、图证和局限表达。
- 编辑部社论、报告指南与政策：补充明确的编辑或报告要求，并记录适用范围。
- 出版后 PDF：观察出版版式；它可能经过出版社排版，不能据此断言作者应提交同样字体或栏式。

优先找当前期刊与文章类型的官方 Word/LaTeX 模板；没有找到时记录检索范围，检查是否允许自由格式或存在通用模板。不得将下载不明网站的“模板”包装成官方来源。

选择少量可回读且有代表性的近年样本开始分析，再按实际差异补充。比较相同修辞功能的段落，解释段落如何提出问题、安排证据和限制主张。将有来源的写作观察与官方硬要求分别记录；几篇文章中常见的写法只支持样本内观察。

结合当前稿件与证据提出适配：什么内容需要前移、补足或压缩，为什么有助于目标读者。保持研究条件、证据强度与作者原意；风格适配不能增强科学结论。需要实际改写时使用现有 academic-paper-writing、corpus-assisted-writing 等适用技能及已确认的论证；涉及论文承诺、兑现或漏斗结构的选择先取得作者确认。

适配记录可以沿用稿件项目的现有规范，保留“要求或观察—来源—稿件位置—实际处理—剩余差异”。完成后对照实际作者指南检查，排版由 template-fidelity 分支核验。

例：[IEEE 官方模板入口](https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/authoring-tools-and-templates/tools-for-ieee-authors/ieee-article-templates/)引导到 Template Selector。它支持实际检索，不能替代用户目标期刊与文章类型的确认。
