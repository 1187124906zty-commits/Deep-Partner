# 表达判据：意义是否完整、清楚且有层次

本文件用于起草与审读。以目标读者初次接触当前文字时能够得到的理解作判断，结合章节目的、相邻段落和实际研究材料。EASE的完整、清楚、简洁提供总体尺度，以下六个角度将尺度落实到正文。

|角度|读者应能够理解什么？|起草和修订的着眼点|
|---|---|---|
|R1 对象与概念|正在研究谁或什么，术语、符号与指代具体指向哪里。|建立概念定义，稳定命名，按当前上下文区分同类对象。|
|R2 动作、关系与范围|对象怎样联系，进行了什么比较，陈述在哪些条件下成立。|准确表达动作、比较量、基准、条件、归属与判断程度。|
|R3 句段推进|本段建立什么认识，各句为何按当前次序展开。|使起点、解释、证据、比较和当前判断相互承接。|
|R4 研究目的与重点|当前内容怎样推进论文希望增加的认识。|按贡献、读者与小节用途分配强调对象和解释深度。|
|R5 信息完整性与层次|理解和评议当前判断需要什么，相关细节在哪里查到。|补足必要前提，安排定义、方法理由、图表及可复核细节。|
|R6 语料与来源适配|采用的素材和写法怎样服务同一个对象、问题与论述。|回查来源功能和科学内容，将目标对象、关系与范围写进新正文。|

## R1：以概念与上下文确定命名精度

研究对象、量、参数和方法在首次需要时获得足够定义。近义术语通过实际含义区分，例如测量信号、重构状态和识别材料关系各自说明对应对象；缩写、样品标签和符号按其阅读场景介绍。

定义落实到当前研究。材料名称说明所讨论的样品或体系；物理量说明测量或计算的属性；函数说明因变量、自变量及其物理联系；模型参数说明所属方程、含义及本次研究中给定或待估的身份。例如，热扩散率、温度场、温度传感器读数与神经网络权重各有不同用途，依据实际模型分别命名。专业读者已熟悉的通行概念可以简述，本研究特有的对象和用法在首次判断需要它们时交代。

概括名称承接已经建立的具体内容。读者读到“材料性质”“模型参数”“识别结果”时，能够从当前句及前文确定涉及哪些量、哪一组参数和哪项输出。首次引出内容时，用实际名称或紧接的解释建立这一对应；解释充分后，根据段落推进需要使用概括名词。摘要、图注及独立节选按各自的阅读起点建立必要对象。

专业词和概括词在当前科学语境中具有清楚的含义。按实际对象选择它们，例如土柱的土层、测试的处理组和误差的比较对象分别命名；讨论几项不同测量时，直接说明每项测量与待估性质的联系。词语的抽象程度由前文已经建立的内容和本句所作判断决定。

新的方法名称和评价对象接到前文已经说明的动作。前文建立观测与目标量的联系后，当前句说明这个求解过程的名称和用途，后文再用该名称讨论结果。命名、分类和评价各有相应的内容承接，专业名词在需要时获得当前研究中的含义。

指代的充分性由读者能否恢复到明确对象决定。前句只讨论一种催化剂时，“该催化剂”可以继续推进；前句并列两种催化剂时，用实际名称说明下一句讨论哪一种。跨段、跨节或独立阅读的摘要与图注，按各自需要重新建立对象。

已建立的名称适当重复有助于概念稳定，概括名词则说明作者如何理解前文，例如“这一比较”“这种限制”“该观察”。名称与前文实际内容相对应后，再增加新的信息。

## R2：用准确关系和限定表达科学意思

动词使读者辨认测量、估计、预测、识别、改变、比较或解释。句子的主语、动作与作用对象共同表达研究含义；限定成分贴近它所限定的对象或命题。

方法动作写出当前任务中处理什么、怎样处理以及得到什么。介绍参数估计时，说明使用的观测、连接观测与待估量的模型，以及所估计的具体系数或函数；介绍分类或重构时，同样说明输入对象、采用的判断或映射与输出含义。原件只支持其中一部分时，正文使用已确认的信息，并继续取得影响其余表述的资料。

比较说明双方、共同条件、评价量和基准；数量表达说明单位、分母与范围。报道观察、引用前人判断、给出本次解释和提出待检验设想，各自使用相符的归属及语气。明确的研究结果可以直接陈述，解释与推广按依据限定。

例如，“吸收峰发生变化”可依据资料展开为哪个样品、哪个峰位、相对什么基准及在哪种处理后发生变化。具体程度以当前判断需要为准。方法段说明测量过程，结果段呈现变化，讨论段解释变化对目标关系的意义。

## R3：用句子关系共同发展一个认识

先确定本段要使读者获得的认识，再安排事实与解释。入口句给方向，后续通过定义、例证、比较或证据发展它，段尾形成当前判断或继续下一问题。推导、现状综合和结果说明可以采用不同次序。

逐句读回时，说明后句怎样接住前句：解释概念、补充条件、增加对照、支持判断，或依据已形成的认识提出问题。语言上的衔接与意义上的联系共同建立连贯性。来自不同原段的素材以当前共同问题重组，必要解释从已读材料展开。

因果和推论连接有可说明的依据：前句提出哪些事实或关系，后句由它们得到什么判断。先将这项联系写清，再按目标语言的话题次序安放连接词及其作用范围。中文用自然的语序展开完整意思，具体词序依本句主干与上下文判断；概括评价由相应的科学作用和后果支持。

句内让主要信息进入主干，依存成分保持容易辨认的联系。英语的主语、谓语、话题位置与强调位置帮助判断信息重点；中文依据自己的语序与篇章习惯安排。长短与语态随内容及信息关系选择。

以完整命题审读正文句子：主干作出了什么判断，动词所需的对象或补语是否齐备，条件与目的成分依附于哪一主句。中文省略成分由明确上下文承接，英语分句满足相应语法结构。发现读者需要补出动作对象或主要判断时，取得实际内容并补入本句，或将依存成分接回所属主句。同级标题及并列内容以相称的语法形式和概念层级标示各自作用。

## R4：以研究贡献和小节用途共同确定重点

读者需要判断研究增加了什么认识。方法创新展开关键变化、理由及能力检验；方法应用展开方法怎样帮助获得对象认识；现象研究展开观察、比较与解释。混合研究据实际贡献安排两层内容，详见[写作目的](writing-purpose.md)。

小节承担自己的信息任务。应用论文中的模型定义小节可以详细解释模型，测量小节可以展开观测，比较小节可以讲清参照。它们的用途与全文问题相连，读者便能理解细节为什么出现。

审读强调对象、解释深度与落点，依据内容对主要问题的实际作用调整篇幅。术语次数可以提示注意位置，重点判断继续依赖段落在说明什么。

全文审读同时复述中心问题、材料支持的回答及其学术意义。沿各章的主要判断查看回答怎样建立：前文提供必要前提，比较贡献相应依据，讨论解释这些依据的意义。对本问题有用的语料据此归入适当段落；段落落点共同推进全文回答。摘要与结论按各自用途呈现这个回答及其范围。

正文以具体科学困难建立研究需要，再展开本文的研究行动。困难来自已述观察、文献比较或模型在当前对象上的表现；行动说明研究哪一材料、改变哪一条件、取得哪些资料及比较什么。写作取舍与材料整理过程留在工作笔记，论文通过实际科学内容发展论点。

## R5：以读者需要分配完整性与简洁性

完整性包括理解当前问题、方法和判断所需的前提、定义及依据。专业读者需要足以评议与复核的细节，较少接触该问题的读者需要概念背景与意义解释。正文、表格、图注、附录和补充材料协同安排这些需要。

正文讲清关键选择、关系和判断，图表呈现相应数据及必要单位，常规设置在适合查阅的位置说明。摘要与图注按独立阅读要求提供信息；跨章重复按该位置的理解任务判断。

删减时保留使判断成立的内容，归并重复事实和重复评价。补写时先确定缺的是对象定义、逻辑前提、证据位置还是来源认识，再用相关材料展开。

## R6与判断记录

语料适配按[语料与段落](corpus-and-paragraph.md)审读。重要表达同时对照原段功能与新段目的，核对被填入的对象、关系、条件和立场。

每项判断写出“当前文字—读者理解—充分程度—修订或保留理由”。使用“表达清楚”“需要修订”“需要补充材料”“本项不适用”表达实际结论。判断落实到具体位置与连续改稿；读回后说明原来的理解困难是否解决。

按首次阅读的顺序，从标题、摘要和正文读到当前句，用已出现的文字复述它的科学含义：谈论哪个对象、作了什么判断、判断涉及哪些量及其关系。复述需要自行补出对象、参数或方法步骤时，回到相应来源取得具体内容，写入读者需要它的位置。顺序读回与来源核对共同完成：来源核对确认事实，顺序读回确认事实是否已在正文中说清。
