# 科研写作语料库

语料库帮助写作者理解真实论文的科学内容与表达意图，再将这些认识用于作者的研究。连读原段及相邻内容，说明它讨论的对象、已经建立的事实、各句解释的关系及段落形成的判断；据此选择术语、搭配和展开方式，用本文材料写成连续正文。

本项目的General来自CNS文章，帮助学习通用学术表达与论述方式；Custom沿用已整理的专业语料，帮助理解术语、搭配和领域研究内容。两类材料结合使用，按当前写作问题逐步补充。检索围绕材料、力学、计算科学和工程词汇展开。

已有研究认识和读过的范例可以直接帮助成文，新的调查回应尚需理解的内容或表达选择。采用原段时，用准确而普通的语言讲清其科学意思，按本文目的判断适合的写法。原段中的对象、动词及结论一起决定句式用途；新稿的关系由本文材料建立，正文持续讨论实际样品、过程、测量及发现。引用前人的认识时注明来源，学习常规语言模式时按本稿论点重组句段。

按作者需要交付实际正文或明确的语言调查，并在简短笔记中说明哪些来源提供内容、哪些范例帮助了搭配、句式、段落或章节安排。全文主线结合academic-writing-guide，起草与读回结合scientific-expression-review。重要学习记录可用[语料笔记](assets/corpus-notes.md)，学术依据见[来源说明](references/sources.md)。
