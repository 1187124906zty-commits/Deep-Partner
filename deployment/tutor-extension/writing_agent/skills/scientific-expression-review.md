# 科学表达规范与审读

科学表达使读者准确辨认研究对象，理解概念和关系，判断陈述的范围，并沿正文获得作者希望传达的认识。严谨性在于意义表达得完整、清楚且有层次；简洁性来自恰当的信息选择。

从当前研究目的、目标读者和材料开始。构思与起草时，按[写作目的](references/writing-purpose.md)确定每章和段落需要表达的内容；写出正文后，按[表达判据](references/criteria.md)检查实际文字。已有稿件可以直接进入审读；只有想法时，与academic-writing-guide和corpus-assisted-writing共同完成调查及成文。

|当前需要|参考及关键作用|
|---|---|
|确定论文贡献、段落重点与解释深度|[写作目的](references/writing-purpose.md)：围绕研究增加的认识选择内容。|
|评估表达是否足以使首次阅读者理解|[表达判据](references/criteria.md)：把完整、清楚、简洁落实到对象、关系与层级。|
|使句式和段落范例服务于当前研究|[语料适配](references/corpus-and-paragraph.md)：比较来源功能与本文任务，审读实际迁移。|
|从全文逐步修订到局部|[分层审读](references/revision.md)：按故事、章节、句段和细节完成实际改稿。|
|保存原句位置及逐段修改记录|[工具使用](references/tool-use.md)：整理审读资料并生成可回查的改稿。|

每项判断联系具体正文：读者已经能够理解什么，哪里还需要解释，以及怎样修改。依据当前来源和研究记录澄清名称、关系、条件、句序与侧重；需要作者确定的科学选择通过有材料的对话解决。

从首次阅读者的位置顺序读到当前句，使研究对象、量、函数、参数所属模型和方法动作在需要它们时具有具体含义。来源核对确认科学事实，顺序读回确认这些事实已在正文中说明。

交付作者所需的连续正文，具体判断与来源采用记录另存写作笔记。修改后读回相关段落、邻段及全文主线，确认科学意思、解释深度、量、条件和来源归属。表达判断关注证据如何被呈现，研究有效性由相应实验、分析与理论资料支持。[来源说明](references/sources.md)区分指南机制与本项目应用。
