# 独立任务卡与固定执行流程

网站与本轮 Windows 包使用构建 25228885。沿用当前研究项目、会话、成果区和现有后台执行器，没有建立第二套聊天或任务执行系统。

任务面板在右下角展开，保留背景内容可见。每次实际执行都有独立卡片，按具体论文、材料包或稿件命名。同一类型的多次执行分别保留。面板按内容确定高度，可筛选进行中、全部和已完成；已完成任务默认收起，详细过程可以展开。

每类任务从同一份服务端流程定义取得步骤，开始时保存本次流程版本。当前已接入以下 11 类工作台后台任务：

| 任务类型 | 固定阶段 |
| --- | --- |
| 材料导入 | 检查材料包 → 保存文件 → 整理稿件 → 加入项目 |
| 文献下载 | 下载全文 → 核对 PDF → 上传集群 → 验收副本 → 加入文献库 |
| 文献分类 | 读取材料 → 整理分类 → 核对来源 → 保存分类 → 阶段评审 |
| 稿件导出 | 准备正文 → 生成版式 → 保存文件 → 阶段评审 |
| 稿件翻译 | 翻译段落 → 核对版本 → 保存译稿 → 阶段评审 |
| 模板解析 | 读取模板 → 解析版式 → 保存预览 |
| 汇报内容生成 | 读取研究材料 → 组织汇报内容 → 保存内容计划 → 阶段评审 |
| 汇报导出 | 生成可编辑页 → 渲染预览 → 检查页面 → 保存文件 → 阶段评审 |
| 阶段评审 | 核对评审对象 → 独立评审 → 核验检查项 → 保存评审结果 |
| PDF 译文导出 | 读取原文与译文 → 保留公式与版面 → 生成 PDF → 保存译稿 |
| 期刊排版预览 | 核对作者资料 → 核对期刊版式 → 生成排版预览 → 保存预览 |

步骤由实际执行回调推进。翻译段落与材料文件可以显示真实完成数；无法量化的过程显示当前步骤，不按经过时间编造百分比。等待下载设备时标为等待，失败时停在出错步骤，后续步骤保持未开始。条件分支中没有运行的步骤明确标记未运行，不会伪装完成。评审通过与否保留实际结果，产物保存成功不等于评审通过。

任务阶段、计数与执行记录保存在现有任务数据库中，刷新和重新打开面板可以恢复。旧任务没有记录的过程会说明未记录，保留其现有结果；已有下载阶段记录可以直接回读。文献下载沿用已有重试与取消接口。任务产物链接可以打开到当前工作区的原生文件侧栏。

验收包含真实的小型材料导入、独立任务卡、真实 API 状态变化后的步骤推进、错误步骤与后续未执行状态、刷新恢复、四种主题、窄屏布局、关闭操作及产物侧栏。翻译进度和失败情况使用隔离项目的界面事件演练，不声称实际完成了译稿或汇报。验收没有调用研究模型。
