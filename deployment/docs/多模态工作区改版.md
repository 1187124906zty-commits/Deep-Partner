# 多模态科研工作区

本次按科研材料和日常操作重新组织现有共享前端。左侧可直接打开文献、文件、论文、图表、PPT 和程序；内容工作区承担查看、编辑和审阅，助手可在右侧展开。网站和 Windows 程序使用同一前端。

## 入口与内容

- 资料：文献、文件。文献保留检索、上传、题录与原文阅读；文件显示项目全部材料。
- 创作：论文、图表、PPT、程序。图表和程序复用文件能力，按内容类型筛选，分别接到原有图形检查器和代码查看器。
- 研究对话与近期会话保留在左侧；修改记录、本机任务和设置位于底部。项目切换、新建和导入集中在项目选择行。
- 项目普通入口恢复上次内容分类，新项目默认显示项目文件；明确指向会话的链接进入该会话。

## 工作区

移除主界面的“对话 / 成果 / 并排”切换层和重复的成果导航。顶栏显示当前项目与内容类型；内容占据主要宽度，助手按需展开或收起，可拖动分隔线或用方向键调整宽度。窄屏将助手显示为内容上方的面板。

论文保留编辑、双语对照、历史、翻译、排版与导出，并补上可见的“阅读”入口。工具栏中的下拉框按内容宽度显示。PPT 的生成、审阅、导出与播放放在同一工作区；播放支持方向键、Home、End 和 Esc。原生 Dito 在右侧助手范围内打开，当前文档继续可见。

## 验证与适用范围

验收使用既有软件验证项目和原有会话，不生成新的模型回答，不向研究项目导入材料。代码打开使用真实项目文件。该项目没有保存的 PPT，因此播放操作额外使用浏览器内的两页界面测试响应，不把它当作真实研究汇报，也不写入服务器。

构建与验收记录：`reports/unified-ui-build.json`、`reports/compact-ui-candidate.json`、`reports/compact-ui-published.json`；发布记录为 `reports/compact-ui-release.json`。页面截图位于 `reports/screenshots/compact-*`。

## 主题、选中框与模型入口修复

2026-11-02 的后续修复构建为 25206644。

“研究对话”按钮错误匹配了侧栏小图标按钮的宽度规则，可用空间 203px 时按钮只有 43px，导致选中背景只覆盖文字附近。宽度规则现仅应用于新建等小图标按钮，研究对话与其他导航行保持整行宽度。

输入框中的静态“AI 助手”已替换为原生模型选择器，默认显示当前模型名。模型菜单复用真实服务列表与会话 `setLLMSelection`，选择结果进入 `start_turn.llm_selection`；发送参数验证通过浏览器 WebSocket 拦截完成，未实际触发模型回答。

玻璃主题的 `--card` 是半透明白色，嵌入式内容的五层容器重复绘制，叠加成大块灰色。修复在嵌入内容根处将 card、secondary、muted 按当前深色底色合成为稳定表面，避免继续叠亮。其他主题保持原有变量。通过设置实际依次切换纯白、玻璃、深色、奶油并恢复原主题，玻璃内容区像素由 RGB(75,74,84) 恢复为 RGB(28,28,40)。

针对性回归见 `reports/theme-model-reproduced.json`（修复前失败）、`reports/theme-model-candidate.json` 和 `reports/theme-model-published.json`。实际 Windows 包检查见 `reports/compact-ui-native.json`。
