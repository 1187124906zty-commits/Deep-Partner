# 命令行上传项目文件

`dp.exe` 支持查看当前账户项目、上传文件和文件夹、按文件类型归类，以及列出已保存的项目文件。所有操作沿用现有项目权限和上传接口。

PowerShell 中先设置命令位置，并登录同一个 DeepPartner 账户：

```powershell
$dp = "$env:LOCALAPPDATA\Programs\Deep partner\dp.exe"
& $dp login --username "你的用户名"
& $dp project list
```

登录会隐藏密码输入；会话由 Windows 为当前用户加密保存。已在桌面启用记住设备时，命令行也可以复用已有设备凭证。脚本可使用 `login --username ... --password-stdin` 从标准输入提供密码，避免将密码放在命令参数中。会话过期后重新登录。

上传单个文件，项目可用完整名称或 ID：

```powershell
& $dp project upload --project "水分扩散" "D:\研究材料\main.py"
```

默认 `--category auto` 按扩展名分类：

| 文件 | 保存位置 |
|---|---|
| PDF | 文献库，默认“阅读材料” |
| Python、MATLAB、C/C++、配置等 | `project/src/` |
| CSV、Excel、NumPy、HDF5、MAT、VTK 等 | `project/data/` |
| PNG、JPEG、SVG、TIFF 等 | `project/figures/` |
| PPT、PPTX、ODP | `project/slides/` |
| Word、Markdown、TXT、LaTeX 等 | `project/docs/` |
| 其他格式 | `project/files/` |

文献同时执行原有 PDF 题录识别。识别是否匹配会保留在返回的 metadata 中；“已保存”不代表识别一定成功。此命令不启动项目知识库索引。

先查看整份材料目录的归类，再上传：

```powershell
& $dp project upload --project "水分扩散" "D:\研究材料" --recursive --dry-run
& $dp project upload --project "水分扩散" "D:\研究材料" --recursive
```

文件夹上传保留来源文件夹名称与其内部结构；PDF 按文献用途存放并保留文件名。本批次出现相同目标文件名时会要求分批，避免同批文件互相覆盖。递归上传略过 `.git`、`.venv`、`node_modules`、`__pycache__`、`target`、链接和 `.env*` 文件。它是材料上传，未承诺完整复制开发环境。

将 PDF 指定为方法框架，或把多个文件一次上传：

```powershell
& $dp project upload --project "水分扩散" "D:\论文\method.pdf" --purpose methods
& $dp project upload --project "水分扩散" "D:\研究材料\main.py" "D:\研究材料\values.csv"
```

`--purpose` 支持 `references`（参考文献）、`methods`（方法框架）、`validation`（验证数据）、`reading`（阅读材料）。此参数只影响 PDF 的文献用途，不推断论文的学科分类号。

手动指定文件分类或存储目录：

```powershell
& $dp project upload --project "水分扩散" "D:\研究材料\model.json" --category data
& $dp project upload --project "水分扩散" "D:\研究材料\plot.pdf" --category figures
& $dp project upload --project "水分扩散" "D:\研究材料\main.py" --path "src/experiment-1"
& $dp project files --project "水分扩散" --path src
```

`--category` 可用 `auto`、`literature`、`code`、`data`、`figures`、`slides`、`documents`、`files`。`--path` 为项目文件根下的相对目录，只作用于未进入文献库的文件。

同名文件沿用工作台的版本保存行为：更新当前文件，旧文件进入项目可恢复历史。PPT 和 Word 在此作为项目材料保存；需要替换当前稿件或作为 PPT 模板时，仍使用对应编辑器的明确导入操作。

需要脚本读取结果时加 `--json`：

```powershell
& $dp project list --json
& $dp project upload --project "水分扩散" "D:\研究材料" --recursive --json
& $dp logout
```

JSON 在标准输出，进度在标准错误。每个文件返回保存位置、成功或失败和服务端回执；只要有文件失败，命令退出码为非零，已经成功的文件保留。PDF 单文件上限为 100 MiB，其他文件为 256 MiB，并遵守当前账户的工作台容量限制。
