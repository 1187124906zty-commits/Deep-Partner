## 新项目的日常使用

创建项目后直接进入研究对话，拖入或粘贴图片、PDF、文档、程序。附件先保存到当前项目；PDF 同时进入文献库，能提取的文档或程序文本参与项目检索，并在后台加入原生语义索引。重复上传沿用已有材料；索引失败时保留原文件和已提取文本，显示具体状态。

对话中的上传图片可预览，发送后直接显示在消息中。“查看网页”会打开原生侧栏网页标签页；网页不允许嵌入时可使用“阅读正文”，也可在外部浏览器打开。某些需要登录或交互的网页仍应使用外部浏览器。

复杂的“导入项目”入口从日常界面移除，导入后不再强制等待额外阶段评分。现有 API 与评审模型配置保留。侧栏仅保留“创作”分组，文献和知识库合并为底部一个入口。

## 图形与 Dito 的职责

已关联绘图对象的图片继续使用原有图形画布。点击文字、曲线、图例、散点或坐标轴即可打开对应属性；图层选择返回该对象的样式，文字字体和字号直接展开。元素支持拖动、方向键微调、撤销、重做、保存及重新打开。保存失败会保留修改，并持续显示错误和重新保存入口。

图形内不再打开独立 AI 修改面板；“问 Dito”使用现有侧边栏。普通位图仍使用图像标记与选区能力，不会声称任意 PNG 已自动分离为可编辑的文字、曲线或坐标轴。

Dito 自动跟随当前打开的位置：

- 论文编辑：当前段落或选文、文档版本和未保存状态。
- 原文阅读：文献、页码、选文或当前页解析文本。
- 程序：当前文件、语言、行号与选中代码。
- 图形：当前图片、选中对象、未保存样式和实际画布预览。
- PPT：当前页、稳定页面 ID 与该页内容。

当前位置显示在 Dito 输入区，切换材料会更新；可取消“跟随当前位置”。发送时读取当前上下文，知识库始终使用当前项目已绑定的范围，不为每张图、每个文件或每次侧栏提问创建新知识库。
