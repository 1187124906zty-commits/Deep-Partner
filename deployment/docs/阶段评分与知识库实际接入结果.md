# 阶段评分与知识库实际接入结果

更新：2026-11-02。本文件记录已实现行为与实际验证。三本教材和六用途资料的最终页数、状态、路径以本文件末尾链接的解析回执为准。

工作台入口为 [研究工作台](https://tutor.example.invalid/research/)。在“工作台设置 → 模型与检索 → 独立评审模型”中选择跟随 Tutor，或配置单独的 OpenAI 兼容接口、模型和 API Key。“工作台设置 → 阶段评分”提供全部阶段；论文和 PPT 区域也提供阶段评分入口。

## 已生效的流程

用户确认的 Q1–Q6 已记录在 `reports/quality-design-decisions.json`。评审默认沿用 Tutor 账户模型，独立组织上下文；作者写作接口的自定义设置不会悄悄改变默认评审选择。自定义评审接口可单独选择模型；声明支持图像时才发送实际渲染页图，并记录页面与覆盖。未见图像的评审明确为文本评审。

13 个阶段为材料解析、问题界定、文献与现状、研究方案、证据与结果、科研程序、图表、稿件、翻译、PPT 内容计划、PPT 导出、审查意见和最终交付。各阶段使用适合当前用途的维度，分项 0–4，核心项分别至少 3。硬条件单独检查；必要检查缺失时仍为 unknown。百分制用于展示，不能抵消低于要求的核心项、关键失败或证据缺失。

评审实际读取所选项目文件与来源，保存材料版本、规则版本、定位、分项理由、具体问题、输入截断与检查覆盖。来源、文件或规则改变后，旧结果失效。作者可以明确确认当前偏差并写明理由，历史评分保留；作者继续不被记录为自动通过。未创建的产物返回“尚未评审”，不会因为查询放行状态而报服务错误。

PPT 内容规划已连接最多两轮定向修订与复评：只修改问题定位的页面及允许的措辞、布局字段，保留来源和事实。数字、否定、确定程度或研究结构需要改变时交给作者；模型调用期间用户改稿时保留用户当前版本。其他阶段返回评分与可执行问题，由相应执行器或作者处理；本轮没有为所有格式建立自动改写器。

材料导入、文献分类、稿件导出、翻译和工作流交付已接阶段评审任务。交付回执保存原有文件写入结果，另外返回质量任务和当前版本 gate。PPT 导出读取当前计划的评分与来源绑定。外部自动流程应读取 gate，再决定下一阶段；文件保存成功和质量通过有各自的状态。

## 六种 PPT 用途

生效来源是工作台的 `templates/presentations/purpose-rules.json`，规划和评分读取同一用途卡。三种视觉主题是可替换的产品选择；用途与主题分别选择。私人模板已解析的字号优先，缺失值保留产品回退身份。母版、主题、布局和全部字体继承的完整恢复仍有边界，不能仅凭这次字号修复声称任意模板均已逐对象保真。

| 用途 | 节点评价重点 |
|---|---|
| 组会讨论 | 问题、必要条件、进展与异常、竞争解释、可回答的反馈问题 |
| 学术报告 | 听众理解、研究贡献、关键证据、给定时间内的信息取舍 |
| 项目汇报 | 目标、实际交付、证据与偏差、依赖风险和需要决定的事项 |
| 开题报告 | 问题价值、方法依据、可行性、验证方案、计划与已完成工作的区别 |
| 学位答辩 | 已完成研究、作者贡献、方法证据、各部分关系或合理独立分组、限制 |
| 文献研读 | 原文身份与条件、方法机制、关键图证、贡献局限、自己的解读与迁移条件 |

机构指南提供条件性的来源支持，学校、会场和项目合同的明确规定仍按当前任务绑定。原来源、官方替代材料与产品综合规则分别保留身份。

## MinerU 路线与质量判断

用户最新指令允许复用现有云端配置，本轮使用实际已配置的 MinerU 云服务。六页样本及 AWG3 第172页单页复测均已真实执行。请求使用公开接口参数；没有发送猜测的高精度字段。返回生产元数据为 3.4.4 / hybrid / medium，本次没有完成云服务与集群自托管同条件精度比较。

原始云 Markdown 存在跨书相邻样本段落串接、图示措辞漏词；单页复测仍有漏词。按物理页结构恢复可纠正来源归属，独立原页裁片与文字层/代理视觉补充可补足已定位的图示缺漏。组合样本的 38 个关键锚点通过核对。原始输出、自动恢复和补充层分别保存；代理视觉审读不等于真人审读。

全书按最多180页分片、并发1执行，保存既有 batch_id 和完成检查点。输出包括原 PDF、MinerU 原始 Markdown/JSON/图片、按源物理页恢复的 Markdown/JSON、来源页映射、结构风险队列及私有集群接收回执。临时签名URL状态不随交付包扩散。结构覆盖通过说明产物和映射可用；尚未逐页检查的正文继续标为 unreviewed。引用具体教材指导时，仍需回到相关原页核对条件、措辞、数字和否定。

三本教材原件与完整解析包保留在私人位置，没有放进网站公共静态目录。六用途 HTML 同时保留原始网页与去导航的解析输入；原生提取 fallback、MinerU 结果和未取得原件分别记录。图表、公式与复杂表格的正确性按实际检查覆盖报告。
