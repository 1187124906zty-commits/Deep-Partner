# 模型生成取消固定超时

2026年11月3日，按作者明确要求，生产 DeepTutor 的模型生成等待改为无固定期限。Agent 建立请求与读取输出、OpenAI Responses/Chat Completions、Anthropic、Azure 和 Codex HTTP 客户端均取消本地固定时长。已有 final 标签也不会因静默8秒而提前结束尚未完成的模型流。模型明确完成后的用量尾帧收集保持原行为。

当前 `gpt-6.1-sol / max` 的模型配置继续使用；模型沉默期间持续等待，作者可以手动停止。上游明确返回繁忙、限流、HTTP错误或真实断开时继续返回错误。前端已有的空闲恢复只重新订阅同一任务，不把静默判定为任务失败。

修改由 `ops/remove_model_timeouts.py` 根据已部署的真实源码生成。七份修改后的源文件存于服务器 `/srv/dify-research/model-wait-policy/`，通过现有 `/srv/deeptutor/compose.override.yaml` 以只读文件挂载到原路径，容器重建后仍生效。更换上游版本时应对新源码重新应用并验证这些修改。

发布前，受影响会话已确认没有活跃轮次；随后重新加载服务，健康状态正常。原会话及最新用户请求仍可读取。此次维护没有重新发送研究任务；原会话的旧失败记录仍是历史终态，下一次重试使用新服务。

验证使用生产容器中的真实模型代码。加速回归在旧代码上得到5项失败、1项错误；修复后及部署后9项全部通过，覆盖延迟输出、Responses与Chat Completions、三个SDK的无期限设置、明确繁忙错误以及取消等待。另启真实本地SSE服务，先发起流，再静默100秒；经过SDK、Provider适配器和Agent读取层，100.608秒后正常返回 `WAIT_POLICY_OK`，只发出一次HTTP请求。这个测试没有调用外部模型。

同一路由的真实 `gpt-6.1-sol / max` 短请求返回 `MODEL_WAIT_POLICY_OK`，SDK和Agent期限均为null。它证明正式模型连接可用，不代表此前完整文献综述已经完成。
